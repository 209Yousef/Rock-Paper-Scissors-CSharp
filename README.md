# Rock Paper Scissors - C#

## About the Project
A console-based Rock Paper Scissors game developed in C# as a programming practice project.

The player competes against the computer, which makes random choices. The game determines the winner using conditional statements.

## Features
- Player versus computer gameplay
- Random computer choices
- Winner determination
- Game logic organized into functions

## Technologies
- C#
- .NET Console Application

## Concepts Practiced
- Conditions
- Loops
- Functions
- Enums and structs
- Random number generation

## How to Run
1. Download or clone this repository.
2. Open the `.sln` file in Visual Studio.
3. Build and run the project.
